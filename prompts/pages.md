| **ファンクションキー** | F4:戻る(neutral-600), F3:画像(purple-700,無効), F1:確定(emerald-700,無効), F2:履歴(blue-700,無効) |

### タップ時の遷移ロジック
- PENDING有り → タスク開始API → P21 データ入力
- PICKING有り（PENDING無し） → P22 出庫履歴（編集モード）
- 全COMPLETED/SHORTAGE → P22 出庫履歴（読取専用モード）

### コースカードスタイル
| 状態 | 背景 | ボーダー | アイコン | バッジ |
|------|------|----------|---------|--------|
| 未完了 | white | neutral-200 | 🚚 (amber-600) | "残X件" (amber-700, amber-100 bg) |
| 完了 | emerald-50 | emerald-300 | ✓ (emerald-600) | "完了" (emerald-600, emerald-100 bg) |

## P21 出庫 - データ入力画面 (OutboundPickingScreen)

| 項目 | 内容 |
|------|------|
| **ページ番号** | P21 |
| **ファイル** | `feature/outbound/.../picking/OutboundPickingScreen.kt`, `OutboundPickingState.kt`, `OutboundPickingViewModel.kt` |
| **ルート** | `outbound_picking/{taskId}` |
| **ヘッダー** | "出庫" + 日付バッジ(amber-100) + 伝票番号 (amber-50 bg, amber-200 border) |
| **主な機能** | PENDINGアイテムを1件ずつ表示し、ケース/バラ形式で数量を入力して登録 |
| **UI要素** | コース情報カード(blue bg)、ロケーションカード(orange bg)、商品情報カード(amber-50 bg, 商品名・JAN・容量/入数/包装)、受注数/出荷数2列構成（ケース/バラ分離入力）、完了確認ダイアログ、画像ダイアログ |
| **ファンクションキー** | F4:戻る(neutral-600), F3:画像(purple-700), F1:確定(emerald-700), F2:履歴(blue-700) |
| **フッターバー** | bg neutral-900, 4ボタン構成 |
| **遷移先** | P22 出庫履歴（F2:履歴）、P20 コース選択（F4:戻る / 確定完了時） |

### ケース/バラ変換
- 受注数（read-only）: `plannedQty` → ケース/バラ算出表示
- 出荷数（editable）: ケース/バラ入力 → `totalPieces = (ケース × capacityCase) + バラ` で API送信
- API送信: `picked_qty_type = "PIECE"` 固定

### F1:登録後の動作
1. サーバーからタスク再取得（カウンター更新）
2. PENDINGアイテムを再フィルタ
3. 次のPENDINGアイテムがあれば表示
4. 全件登録完了 → 完了確認ダイアログ → 確定でP20へ / キャンセルでP22へ

| 条件 | 色 |
|------|-----|
| 出荷数 == 受注数 | emerald-600 (一致) |
| 出荷数 < 受注数 | red-600 (不足) |
| 出荷数 > 受注数 | amber-600 (超過) |

### 2つのモード
| モード | 条件 | 表示 |
|--------|------|------|
| 編集モード | PIKCINGステータスのアイテムが1件以上 | 履歴リスト + F1送信有効 |
| 読取専用モード | 全アイテムがCOMPLETED/SHORTAGE | 履歴リスト + F1送信無効 |

## 画面遷移フロー

### 入庫処理フロー
```
P03 メイン → P10 倉庫選択 → P11 商品リスト → P12 スケジュールリスト → P13 入庫入力 → P12
                                      ↓
                                P14 入庫履歴 ←→ P13 入庫入力（編集）
```

### 出庫処理フロー
```
P03 メイン
  │
  ├─[出庫処理ボタン]──→ P20 コース選択
  │                      │
  │                      ├─[コースタップ（PENDING有り）]──→ P21 データ入力
  │                      │                                   │
  │                      │                                   ├─[F2:履歴]──→ P22 出庫履歴
  │                      │                                   │              │
  │                      │                                   │              ├─[リスト項目タップ]──→ P23 出庫検品 編集
  │                      │                                   │              │                       │
  │                      │                                   │              │                       ├─[F1:保存]──→ P22
  │                      │                                   │              │                       ├─[F3:戻る]──→ P22
  │                      │                                   │              │                       └─[F4:戻る]──→ P20
  │                      │                                   │              │
  │                      │                                   │              ├─[F1:送信]──→ P20（リフレッシュ）
  │                      │                                   │              └─[F4:戻る]──→ P20
  │                      │                                   │
  │                      │                                   ├─[F1:確定]──→ 次のPENDINGアイテムへ
  │                      │                                   ├─[F4:戻る]──→ P20
  │                      │                                   └─[全件登録完了]──→ 完了ダイアログ → P20
  │                      │
  │                      ├─[コースタップ（PICKING有り）]──→ P22 出庫履歴（編集モード）
  │                      ├─[コースタップ（全完了）]──→ P22 出庫履歴（読取専用モード）
  │                      └─[F4:戻る]──→ P03 メイン
```
